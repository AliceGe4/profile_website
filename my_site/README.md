# Alice German — portfolio starter

A one-page Next.js portfolio. Edit the `profile` and `projects` objects at the top of `app/page.tsx` to replace the empty link fields with your own URLs. Empty links are hidden automatically. Check each project description and skills list before publishing.

## Run locally

Install Node.js 20 or newer, then run:

```bash
npm install
npm run dev
```

Open http://localhost:3000. Run `npm run build` before deployment.

## Put it online with Vercel

1. Create an empty GitHub repository and push this folder's contents to it.
2. In Vercel, choose **Add New → Project**, import the repository, and deploy with the default Next.js settings.
3. Add the resulting URL to your job applications. A custom domain is optional.

For a resume button, put your PDF at `public/resume.pdf` and set `profile.resume` to `"/resume.pdf"`. Add GitHub, LinkedIn, email, and project demo URLs when ready. No account credentials or API keys are needed.
